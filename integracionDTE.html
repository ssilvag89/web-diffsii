Documentación API B2B

API de Integración DTE

Permite a un ERP, CRM o software a medida emitir Documentos Tributarios Electrónicos. El integrador envía solo la información comercial (receptor, ítems, fechas). DiffSii completa el emisor, asigna folio CAF, firma con el certificado digital, timbra y envía el DTE al SII.

Base URL de producción: https://saas.diffsii.cl

El integrador no envía XML ni firma. Tampoco debe mandar datos del emisor: se toman de la ficha de la empresa en DiffSii.

Qué hace DiffSii en cada emisión

  1. Valida el payload (RUT, tipo DTE, ítems, referencias).
  2. Completa el emisor desde la empresa autenticada.
  3. Reserva el siguiente folio CAF (Software de Mercado) o deja que Mipyme lo asigne.
  4. Firma, timbra (TED) y envía el sobre al SII.
  5. Registra el documento en el libro de ventas y devuelve folio, trackId y pdfUrl.

Autenticación

Todos los endpoints de emisión requieren JWT. Obtén el token con un usuario de la empresa (idealmente un usuario técnico de integración).

Obtener token

POST /api/auth/login-local

Request:

curl -X POST "https://saas.diffsii.cl/api/auth/login-local" \
  -H "Content-Type: application/json" \
  -d '{
    "email": "integracion@tuempresa.cl",
    "password": "tu_password_segura"
  }'

Body:

{
  "email": "integracion@tuempresa.cl",
  "password": "tu_password_segura"
}

Emitir DTE

POST /api/integration/companies/{companyId}/dte

Headers

  • Content-Type: application/json
  • X-Company-ID: {companyId} (recomendado)

La nota de débito (56) usa el mismo esquema de referencias.

JavaScript (secuencia completa)

async function emitirFactura33() {
const BASE = 'https://saas.diffsii.cl';
const COMPANY_ID = 'a1b2c3d4-e5f6-7890-abcd-ef1234567890';

const login = await fetch(`${BASE}/api/auth/login-local`, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    email: 'integracion@tuempresa.cl',
    password: 'tu_password_segura'
  })
}).then((r) => r.json());

const headers = {
  Authorization: `Bearer ${login.token}`,
  'Content-Type': 'application/json',
  'X-Company-ID': COMPANY_ID
};

const emitido = await fetch(`${BASE}/api/integration/companies/${COMPANY_ID}/dte`, {
  method: 'POST',
  headers,
  body: JSON.stringify({
    tipoDte: 33,
    fechaEmision: '2026-10-17',
    fechaVencimiento: '2026-11-16',
    formaPago: 2,
    referenciaExterna: 'ERP-OC-9988',
    receptor: {
      rut: '76123456-0',
      razonSocial: 'Cliente Demo SpA',
      giro: 'Comercio al por mayor',
      direccion: 'Av. Apoquindo 100',
      comuna: 'Las Condes',
      ciudad: 'Santiago'
    },
    items: [
      { codigo: 'SKU-01', nombre: 'Servicio de consultoría', cantidad: 1, unidad: 'UN', precio: 100000 }
    ]
  })
}).then((r) => r.json());

console.log(emitido.folio, emitido.trackId, emitido.pdfUrl);

const consulta = await fetch(
  `${BASE}/api/integration/companies/${COMPANY_ID}/dte/${emitido.tipoDte}/${emitido.folio}`,
  { headers }
).then((r) => r.json());

const pdf = await fetch(emitido.pdfUrl);
const blob = await pdf.blob();
return { emitido, consulta, blob };
}

emitirFactura33();

Campos

Campo Obligatorio Notas
tipoDte Sí 33, 34, 39, 41, 46, 52, 56, 61
receptor.rut Sí Con o sin puntos. Se valida dígito verificador.
receptor.razonSocial Sí* Puede omitirse si el RUT ya existe en Clientes de DiffSii.
items[].nombre Sí Descripción del detalle
items[].cantidad Sí Default 1
items[].precio Sí Entero CLP, neto unitario
items[].exento No true para líneas no afectas
fechaEmision No YYYY-MM-DD. Default: hoy
formaPago No 1 contado, 2 crédito, 3 sin costo. Default 2
referencias 56 y 61 Documento origen: tipoDoc, folio, fecha, razon

RCV: compras y ventas del SII

Permite a un partner obtener el Registro de Compras y Ventas de la empresa desde el microservicio SII de DiffSii. El integrador no envía clave tributaria: DiffSii autentica al SII con la clave guardada en la ficha de la empresa.

Seguridad: JWT en header Authorization (no en la URL), membresía a la empresa, permiso de módulo (access_compras / access_ventas) y límite de 40 consultas cada 15 minutos.

RCV Partner (sin companyId)

Para partners que no operan una empresa en DiffSii. Se autentican con una llave emitida por Devint y envían el rut y la claveSii del contribuyente. DiffSii no persiste esa clave. El RUT 76.971.597-5 está bloqueado.

Las llaves se crean en el SaaS: Administración → Llaves Partner (solo empresa Devint), donde también se ve el log de consultas por periodo. Header X-Partner-Key. Límite: 30 consultas / 15 minutos.
POST /api/partners/rcv
curl -X POST "https://saas.diffsii.cl/api/partners/rcv" \
  -H "X-Partner-Key: dsii_..." \
  -H "Content-Type: application/json" \
  -d '{
    "rut": "76123456-0",
    "claveSii": "clave_tributaria_del_contribuyente",
    "tipo": "compras",
    "periodo": "2026-09"
  }'
POST /api/partners/rcv/detalle
curl -X POST "https://saas.diffsii.cl/api/partners/rcv/detalle" \

Requisitos en DiffSii

  • Empresa con certificado digital (Software de Mercado) o clave tributaria (Sistema Gratuito SII / Mipyme).
  • CAF vigente del tipo de documento, si emite por Software de Mercado.
  • Resolución SII y RUT envía configurados en la ficha de la empresa.
  • Usuario con acceso al módulo de ventas (emisión) o compras/ventas (RCV).
  • Clave tributaria en la ficha de la empresa para consultar RCV en vivo.

Para inyectar compras/ventas ya emitidas (sin timbrar), usa la API de movimientos B2B.
